# Premium cinematic redesign

## Goal
Refresh the existing SAANSA Productions homepage into a polished, responsive cinematic experience while preserving its current sections, wording, logo, email, links, and videos.

## Work
- Refine the dark-and-gold visual system, typography, section dividers, and site-wide film texture.
- Add a brief branded intro, fixed scroll-aware navigation, progress indicator, and accessible mobile menu.
- Add restrained, scroll-triggered motion to the hero, content sections, cards, slate videos, process timeline, and contact area.
- Add desktop-only pointer treatment and smooth scrolling, while honoring reduced-motion settings and keeping video loading lazy.
- Verify the homepage at desktop and mobile sizes, then check the project build and preserve the existing SEO metadata.

## Technical details
- Keep changes in the existing homepage and global stylesheet unless a small supporting module is needed.
- Use Framer Motion and Lenis for the requested motion and scrolling behavior; avoid changing existing content or video assets.
